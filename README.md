#  Numora

**Numora** is a real-time, interactive multiplayer competition board platform designed for classroom or group games. It allows a host to project questions while players join from their own devices to answer in real-time.

---

##  Features

- **Server-Authoritative Synchronization:** Precise, low-latency target time synchronization ensuring all player screens countdown in perfect unison.
- **Custom Avatar Selector:** Dynamic emoji and color picker with real-time lockouts for taken avatars.
- **Live Leaderboard:** Real-time scoring system and automatic winner placement tracking.
- **Host Projector View:** Central host view featuring category management, custom question packs, and early match controls.
- **Recovery System:** Built-in player password and code recovery request pipeline.

---

##  Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Node.js, Express
- **Real-Time Communication:** WebSockets via Socket.io
- **Deployment:** Render

---

##  How It Works

1. The host launches a room from the Host Projector Interface.
2. Players navigate to the app link on their devices or laptops and enter the 8-digit join code.
3. Once avatars are selected, the host launches the match.
4. Players receive synced question prompts, enter their answers, and compete for top ranks on the live leaderboard.
